# Panel SynerGea - Recreación y Clonación Web

Reconstrucción completa de la aplicación web **Panel SynerGea** basada en la interfaz original desarrollada con Tabler CSS.

## 🚀 Características
- **Single Page Application (SPA)** nativa en HTML5, Vanilla JavaScript (ES6+) y CSS3.
- **Sin dependencias pesadas de build**: Se ejecuta directamente en cualquier navegador web.
- **Persistencia de datos**: Datos dinámicos en tiempo real utilizando `localStorage`.
- **Módulos completos**:
  - Dashboard con métricas y visualización de publicidad de grupo.
  - Mi Cuenta y Estado de Membresía.
  - Estadísticas del Grupo y Exportador a CSV.
  - TPN (Te Presento Mi Negocio) con gestión de reuniones.
  - Recomendaciones Dadas y Recibidas con semáforo de temperatura.
  - Educación: Mis Cursos, Catálogo de Cursos y Unidades Educativas.
  - Gracias por Sumar a Mi Negocio (Negocios Concretados).
  - Comunidad SynerGea (Mi Capítulo, Comunidad Global y Contactos Destacados).

## 🛠️ Estructura del Proyecto
- `index.html`: Estructura principal y contenedores modal.
- `styles.css`: Sistema de diseño basado en Tabler CSS.
- `data.js`: Base de datos inicial y manejador de almacenamiento local.
- `app.js`: Enrutador cliente y lógica interactiva de cada módulo.

## 💻 Instrucciones de Uso
1. Abre el archivo `index.html` en tu navegador de preferencia.
2. Navega libremente por todos los módulos desde la barra lateral.
